# 🌱 Firma HTML Ultra Crop Care

Una firma de correo electrónico profesional y moderna diseñada para Ultra Crop Care, una empresa innovadora en el sector agro-tech.

![Vista previa de la firma](preview.png)

## 🚀 Características

- Diseño horizontal responsive
- Compatible con Gmail y otros clientes de correo
- Estilo moderno y profesional
- Integración de logo corporativo
- Línea separadora verde que representa el compromiso con la agricultura
- Iconos emoji para mejor visualización

## 📋 Estructura de Archivos

```
firma-ancestral-ucc/
├── firma.html       # Plantilla HTML de la firma
├── logo.png        # Logo de Ultra Crop Care
└── README.md       # Documentación
```

## 🛠️ Cómo Usar

1. Clona este repositorio:
   ```bash
   git clone https://github.com/rainbowstain/firma-ancestral-ucc.git
   ```

2. Reemplaza `logo.png` con el logo de tu empresa
3. Abre `firma.html` en tu navegador
4. Personaliza la información en el archivo HTML:
   - Nombre
   - Cargo
   - Correo electrónico
   - Teléfono
   - Dirección

5. Selecciona todo (Ctrl+A), copia (Ctrl+C) y pega en tu cliente de correo

## 🎨 Personalización

Puedes modificar los siguientes elementos en el archivo HTML:

- Colores (actualmente usando #2ecc71 para acentos)
- Tamaños de fuente
- Espaciado
- Dimensiones del logo
